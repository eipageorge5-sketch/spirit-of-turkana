# 🇰🇪 The Spirit of Turkana | Visual Showcase

A documentary-style web experience focused on the culture, resilience, and landscapes of the Turkana region.

## 🚀 The Mission
This project was built to demonstrate how high-quality visual storytelling can be optimized for performance. It is designed to load quickly even on limited bandwidth (3G networks), ensuring cultural stories remain accessible to everyone.

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3
- **Animations:** AOS (Animate On Scroll)
- **Performance:** Lazy loading and image optimization (80% weight reduction)

## 📸 Key Features
- Responsive Grid Gallery
- Animated transitions
- Mobile-first design
