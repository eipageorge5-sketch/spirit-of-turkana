## 📖 About This Project

The Spirit of Turkana is a cultural documentary platform and photo archive documenting the people, landscapes, and traditions of Turkana County, Kenya.

This is not a portfolio project. It is an ongoing documentation mission — built to preserve stories that the world is moving past too quickly, and to create a sustainable platform for cultural advocacy, conservation partnerships, and photography licensing.

---

## 🌍 What This Archive Does

| Purpose | Description |
|---|---|
| **Document** | High-definition photography and film capturing Turkana culture, landscapes, and daily life |
| **Advocate** | Connecting local stories to NGOs, conservationists, and global partners with the resources to act |
| **Sustain** | Self-funding through photography licensing, partnerships, and community support |

## 📸 The Archive

Five chapters currently documented:

| Chapter | Subject |
|---|---|
| 01 — The Living Archive | Traditional Turkana beadwork and cultural identity |
| 02 — The Lifeline | Lake Turkana — the Jade Sea — and its ecological story |
| 03 — The Rhythm of Resilience | Traditional dance and community spirit |
| 04 — Guardians of the Drylands | Indigenous climate wisdom and the Abiro staff |
| 05 — The Path Forward | The ongoing journey of the Turkana people |

More chapters added as documentation continues.

## 🛠️ Technical Notes

Built with performance as a first-class concern — designed to load on 3G networks in Turkana County itself.

| Decision | Reason |
|---|---|
| No JavaScript framework | Zero bundle overhead — vanilla JS only |
| Native lazy loading | Images load only when they enter the viewport |
| CSS custom properties | Instant theming, no runtime cost |
| Intersection Observer API | Scroll animations without layout thrashing |
| Semantic HTML5 + ARIA | Accessible to screen readers and assistive tech |
| Reduced motion support | Respects `prefers-reduced-motion` system setting |

**Target:** 90+ Lighthouse score across Performance, Accessibility, Best Practices, SEO.
